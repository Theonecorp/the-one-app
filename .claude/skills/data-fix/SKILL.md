# /data-fix — 라이브 자료 일괄 수정 (관리자 전용)

**`FIREBASE_*` 가 없으면 멈춘다.** 담당자 세션이면 "관리자에게 넘김" 으로 `/todo` 에 적고 끝.

1. **읽기** — 스크래치 폴더에 읽기 전용 스크립트(서비스 계정 JWT · `datastore` 범위 · `.claude/skills/morning-check/morning.mjs` 의 토큰 · 값 풀기 부분과 같은 모양). 키 · 토큰은 화면 · 파일에 찍지 않는다.
2. **미리보기(드라이런)** — 바뀔 문서 수 · 칸 · 전 → 후 예시 10개 · 합계(금액이면 전 · 후 합계)를 스크래치 폴더에 CSV 로도 남긴다. 예외(못 맞춘 것 · 애매한 것)는 따로 센다.
3. **승인** — 관리자에게 숫자로 묻는다 (`AskUserQuestion`: 진행 · 일부만 · 멈춤). **승인 없이는 쓰지 않는다.** 바뀌는 범위가 미리보기와 달라지면 다시 묻는다.
4. **백업** — 바꿀 문서의 지금 모습 전체를 스크래치 폴더 JSON 으로 (되돌리기용). 매일 새벽 2시 드라이브 백업도 있지만 그 사이 바뀐 것은 이것뿐.
5. **쓰기** — `commit` 의 `update` + `updateMask`(바꾸는 칸만) · 500개씩. **문서를 통째로 덮어쓰지 않는다 · `users` 는 절대 건드리지 않는다.** 칸을 지울 때도 updateMask 로 그 칸만. 매번 `updatedAt` 을 같이.
   번호 카운터(`counters/*`)를 바꿀 때는 앱이 쓰는 칸 이름 · 모양을 `src/` 에서 먼저 확인.
6. **확인** — 다시 읽어 바뀐 수 · 합계가 미리보기와 같은지 · 오류 0 인지. 앱 화면(관리 › 해당 화면)에서 한두 개 눈으로.
7. **보고** — 바꾼 수 · 오류 · 백업 파일 경로 · 되돌리는 법 (백업 JSON 으로 같은 updateMask 쓰기). 남은 예외는 `/todo` 의 관리자 결정 대기에 (금액 없이).
