# /todo — 할 일 장부 (`ops/TODO.md`)

세션 대화는 길어지면 요약되고 세션이 바뀌면 사라진다. **남은 일은 대화가 아니라 장부에.** 모든 세션이 시작할 때 읽는다 (CLAUDE.md).

## 칸 (이 순서 고정)
- `## ⏳ 관리자 결정 대기` — 관리자가 골라야 진행되는 것 (선택지 · 추천을 한 줄로)
- `## 🔧 저장소 밖 반영 필요` — Apps Script 붙여넣기 · 규칙 배포 · 라이브 자료 수정 · 콘솔 설정 (어느 계정 · 무엇을 · 확인 방법)
- `## 👥 담당자 회신 대기` — 담당자(창고 매니저 · 디자인 담당 …)에게 물은 것
- `## 🗓 다음에 할 일` — 미뤄 둔 작업
- `## ✅ 최근 끝남` — 지운 항목을 7일만 남겼다가 지움

## 한 줄 모양
`- [ ] 2026-11-14 · 무엇 · 왜 · 다음 행동 (관련 PR/파일)` — 사람 이름 대신 역할 · 비밀값 금지 · 한 줄.

## 하는 일
- **보기**: 파일을 읽고 칸별로 오래된 것부터 짧게.
- **경영 숫자 금지**: 장부는 팀 전체가 읽는다. 금액 · 잔액 · 매출 · 수수료는 적지 않고 "숫자는 관리자 세션에서" 로.
- **적기 · 지우기**: 지금 작업 브랜치에서 고쳐 **그 작업의 PR 에 같이** 넣는다. 따로 올릴 때는 장부만 바뀐 작은 PR (`check` 초록 → 관리자 세션이면 squash 머지).
  끝난 항목은 `- [x] … (끝남 날짜 · PR)` 로 `✅ 최근 끝남` 에 옮긴다. 7일 지난 ✅ 는 지운다.
- **작업 끝 보고**: 남은 일이 생기면 장부에 적고 보고에 "📋 장부에 적음: …" 한 줄.
- 다른 담당 세션도 읽고 적을 수 있다. 관리자 결정 칸은 관리자 세션만 지운다.
